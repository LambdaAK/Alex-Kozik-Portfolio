# Portfolio redesign plan (Proposal A: research-engineer one-pager)

Research and rationale: `docs/portfolio-redesign-research.md`.

## Decisions
- Astro 7 + Tailwind v4, static output, no client framework. Deploy on Netlify (unchanged).
- Content lives in `src/data/*.ts` and a `projects` content collection (`src/content/projects/*.md`), so any project can later get a long-form case study by adding a body.
- Homepage order: Hero → Selected Work → ML projects → SWE projects → Experience → Research → Education → Awards → Contact.
- Project grouping stays Featured / ML / SWE. Each project gets `/projects/<slug>` with full highlights.
- Cut: high school, AP Scholar, Boomerang award, "Portfolio Website" project, Skills wall. Tech appears as chips on roles/projects.
- Hero: full name h1, "M.S. CS student at Carnegie Mellon doing RL research; previously Amazon, Salesforce", résumé PDF, email, GitHub, LinkedIn.
- Light + dark theme, system default, toggle persisted in localStorage.
- SEO: title "Alex Kozik – ML Engineer", meta description, OG/Twitter tags, Person JSON-LD, sitemap, robots.txt.
- Images: logos moved to `src/assets/logos/` and rendered via `astro:assets` (auto WebP/resize). PDFs stay in `public/`; `papers/` duplicate removed.

## Tasks
1. Scaffold: package.json, astro.config, tsconfig, netlify.toml, global CSS. Remove React/Vite SPA files.
2. Data: profile, experience, education, awards, papers → `src/data`. Projects → content collection.
3. Layout + components: BaseLayout (head/SEO/theme), Nav (sticky sidebar desktop, top bar mobile, scroll-spy), Hero, ProjectCard, ExperienceItem, PaperItem, Section.
4. Pages: `index.astro`, `projects/[slug].astro`.
5. Assets: move/convert logos; delete unused images; remove `papers/`.
6. Verify: `astro build`, Lighthouse-ish check in browser (desktop + mobile), links resolve, dark mode.
7. Commit on `redesign`; leave `main` untouched until approved.
